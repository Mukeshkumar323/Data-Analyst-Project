# HR Analytics Dashboard

## 📊 Project Overview

The HR Analytics Dashboard is an interactive Power BI project developed to analyze employee data and provide meaningful HR insights.

The dashboard helps understand employee distribution, salary, attrition, experience, training, performance, department, gender, location, and joining trends.

## 🎯 Objectives

- Analyze total number of employees
- Monitor employee attrition
- Analyze average salary
- Compare employees across departments
- Analyze employee distribution by gender and location
- Understand employee experience levels
- Analyze training hours and leave days
- Analyze employee performance
- Identify salary trends

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## 📈 Dashboard Features

- Total Employees
- Average Salary
- Attrition Count
- Attrition Percentage
- Average Experience
- Average Training
- Employee Count by Department
- Employee Count by Gender
- Employee Count by Location
- Average Salary by Department
- Average Salary by Designation
- Attrition by Department
- Employee Count by Performance
- Employee Count by Join Year
- Training Hours by Department
- Leave Days by Department
- Experience and Salary Analysis
