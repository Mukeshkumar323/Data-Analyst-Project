## 🔄 Common Project Workflow

The projects follow a practical data analytics workflow:

1. **Data Collection** – Collect and load the required datasets.
2. **Data Cleaning** – Check missing values, duplicates, data types, and inconsistent entries.
3. **Data Transformation** – Transform and prepare data using Power Query.
4. **Data Modeling** – Create the required data structure and relationships.
5. **DAX Analysis** – Create calculated measures and KPIs.
6. **Dashboard Development** – Build KPI cards, charts, maps, and other visuals.
7. **Interactive Filters** – Add slicers to allow users to explore specific data segments.
8. **Testing & Formatting** – Test filters and visuals and format the dashboard for clear presentation.

These workflows are reflected in the project reports.
